# Prism Theme

A colorful Material 3-inspired theme for Lumen UI. Prism combines primary,
secondary, and tertiary tonal roles with layered surface containers, filled and
outlined controls, state feedback, and emphasized motion.

```ts
import '@luokuiai/lumen-ui/styles.css';
import '@luokuiai/lumen-theme-prism';
```

Apply the theme and choose a color scheme on an application root:

```html
<div data-lumen-theme="prism" data-color-scheme="light"></div>
```

Both `light` and `dark` color schemes are included.
