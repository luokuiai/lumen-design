# Paper Theme

A monochrome, AI-focused theme for Lumen UI with canvas-like surfaces,
high-contrast actions, role-based radii, tabular numerals, and restrained
elevation.

```ts
import '@luokuiai/lumen-ui/styles.css';
import '@luokuiai/lumen-theme-paper';
```

Apply the theme and choose a color scheme on an application root:

```html
<div data-lumen-theme="paper" data-color-scheme="light"></div>
```

Both `light` and `dark` color schemes are included. Change
`data-color-scheme` at runtime to switch between them.
